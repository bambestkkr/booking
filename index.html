      ขั้นที่ 1: เลือกปฏิทิน

      หากใช้อีเมลเดียวกับที่สร้าง Google Apps Script สามารถกรอกอีเมลนั้น หรือเว้นว่างไว้เพื่อใช้ปฏิทินหลักได้ทันที

      ขั้นที่ 2: แชร์สิทธิ์ (กรณีคนละเมล)

      เปิด Google Calendar ของเมลเป้าหมาย → ไปที่ การตั้งค่าและการแชร์ → เพิ่มอีเมลเจ้าของ Script และตั้งสิทธิ์เป็น "ทำการเปลี่ยนแปลงกิจกรรม"

      ขั้นที่ 3: ยืนยันสิทธิ์ Deploy

      เมื่ออัปเดตโค้ดใน Apps Script ให้กด Deploy → New deployment และกด Allow (อนุญาต) สิทธิ์เข้าถึง Google Calendar และ Gmail
